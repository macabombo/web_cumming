# IDENTIDAD VISUAL — Mi Cumming

## Nombre del Proyecto

**Mi Cumming** — Guía Cultural del Barrio Yungay

- **Nombre corto:** Mi Cumming
- **Tipo:** Mapa interactivo + cuenta de Instagram
- **Propósito:** Posicionar al Barrio Yungay y Calle Cumming como destinos culturales y patrimoniales de Santiago

---

## Concepto de Marca

El nombre "Mi Cumming" evoca cercanía y pertenencia — un barrio que es de todos, pero que cada persona descubre a su manera. La palabra "Mi" invita a la apropiación del espacio, mientras que "Cumming" ancla la identidad en una calle específica con historia real.

El isotipo combina un mapa estilizado con la silueta de una ventana colonial, simbolizando la conexión entre el descubrimiento (el mapa) y el patrimonio (la ventana al pasado).

## Tipografías

### Display — Playfair Display
- **Fuente:** Playfair Display (Google Fonts)
- **Pesos:** 400, 600, 700
- **Uso:** Títulos, headings, nombre del proyecto
- **Carácter:** Elegante, clásico, evoca arquitectura patrimonial

### Cuerpo — Inter
- **Fuente:** Inter (Google Fonts)
- **Pesos:** 300, 400, 500, 600
- **Uso:** Texto cuerpo, descripciones, interfaz
- **Carácter:** Moderna, legible, versátil en pantallas

## Isotipo / Logo

### Concepto

El logo de **Mi Cumming** consta de:

1. **Icono (Isotipo):** Un pin de mapa estilizado que contiene la silueta de una ventana colonial. El pin representa el mapa interactivo, la ventana representa el patrimonio.

2. **Logotipo:** La palabra "Mi Cumming" en Playfair Display 700, con "Mi" en un peso regular y "Cumming" en bold para dar énfasis.

### Versión Icono

```
┌─────────────────┐
│       ╱╲        │  <- Techo triangular (ventana colonial)
│      ╱  ╲       │
│     ╱ ▪▪ ╲      │  <- Ventana con detalle
│    ╱──────╲     │
│   │        │    │  <- Cuerpo del pin
│   │        │    │
│    ╲      ╱     │
│     ╲    ╱      │
│      ╲  ╱       │
│       ╲╱        │  <- Punta del pin
└─────────────────┘
```

### Especificaciones de Uso

- **Espacio libre:** Mínimo 16px alrededor del logo
- **Tamaño mínimo:** 24px de alto (icono solo), 120px de ancho (con texto)
- **Fondos permitidos:** Blanco, Verde Yungay, Crema
- **No rotar, distorsionar ni agregar efectos**

### Versiones

1. **Completo (Horizontal):** Icono + "Mi Cumming" en línea
2. **Stacked:** Icono arriba, texto debajo
3. **Solo icono:** Para favicon, avatar de redes sociales
4. **Blanco:** Para fondos oscuros

## Elementos Visuales

### Patrones

- **Líneas punteadas:** Evocan rutas en el mapa (como `--- · --- · ---`)
- **Geometría colonial:** Arcos, ventanas rectangulares, simetría
- **Texturas sutiles:** Tonos papel envejecido, granulado suave

### Iconografía

- **Estilo:** Líneas consistentes, peso uniforme (2px stroke)
- **Biblioteca:** Font Awesome 6 (solid)
- **Categorías con colores propios**

### Fotografía / Imágenes

- **Estilo:** Fotografía callejera, arquitectura patrimonial, detalles de barrio
- **Paleta:** Tonos cálidos, dorados, verdes apagados
- **Filtros sugeridos:** Calidez +10, Saturación -5, Contraste +5
- **Evitar:** Imágenes genéricas de stock, personas sin contexto

### Templates de Stories

1. **Dato del Día:** Fondo crema, texto Playfair, dato en recuadro dorado
2. **Punto de Interés:** Foto de fondo + overlay verde oscuro 60% + texto blanco
